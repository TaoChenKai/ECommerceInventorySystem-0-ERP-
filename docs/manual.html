一、项目简介

0号仓库库存管理系统（原名「星穹」电商库存系统）是一套自研的 PC 端网页版电商库存管理系统，面向电商小店与少量批发的实际业务场景。系统采用 Vue 3 + Vite 前端 与 FastAPI 后端，本地默认 SQLite，Docker 部署可平滑切换 PostgreSQL。

数据自掌控

开源免费或自研实现，不被收费 SaaS 卡脖子。

一套代码多端

本机 Windows、局域网电脑、云服务器经浏览器访问。

三级权限

老板 / 管理员 / 员工，职责边界清晰。

业务闭环

商品 → 出入库 → 采购 → 销售 → 财务 → 分析，附打印 / 渠道 / 审计 / 回收站。

移动端规划为独立项目单独开发（便于分仓库管理版本），不在本版本范围内。

二、技术架构

2.1 总体架构

浏览器（PC / 局域网 / 服务器）▸ 前端 Vue 3 + Vite（Nginx / dev）▸ FastAPI（RESTful + JWT）▸ SQLite（本地）/ PostgreSQL（Docker）

2.2 后端模块

模块说明
app/main.py应用入口、CORS，启动 ensure_schema() 自动建表 / 增量迁移 / 回收站与审计日志自动清理
app/models.pyORM 模型：User / Spu / Sku / Category / StockLog / Purchase(Item) / Sale(Item) / Channel / LabelTemplate / AuditLog / UserPreference 等
app/routers/16 个业务路由：auth / spus / stock / purchase / sales / finance / analysis / channels / label / label_templates / recycle / users / settings / audits / uploads 等
app/schemas.py · security.py · deps.pyPydantic 模型；bcrypt + JWT；get_current_user / require_role("boss","admin")
app/config.py读取 .env、SQLite 路径归一、存储迁移、AUDIT_RETENTION_DAYS 等
app/database.pySQLAlchemy 引擎 / Session，SQLite 与 PostgreSQL 双数据库适配

2.3 前端模块

模块说明
src/views/18 个页面：Login / Dashboard / Products / ProductForm / Recycle / StockInOut / StockLogs / Purchase* / Sales* / Finance / Analysis / Channels / LabelPrint / UserManage / AuditLog / SettingsDialog
src/components/Layout（侧边栏）、ThemeBackdrop（主题背景）、StarField（粒子星云）、ImageUploader 等
src/router/index.js路由 + 角色守卫（meta.roles 控制财务 / 回收站 / 账号 / 日志仅管理员可见）
src/utils/theme.js主题色板、偏好应用、本地缓存兜底 + 后端校准（v1.3.3）
数据库兼容：ensure_schema() 的 _table_columns() 按库类型分支——PostgreSQL 走 information_schema.columns，SQLite 保留 PRAGMA table_info，迁移逻辑两库共用一套代码。

四、功能特性全景

4.1 账号与三级权限

老板：全部权限 + 账号管理（创建 / 删除管理员与员工，老板账号唯一不可删、不可接口创建）；管理员：业务增改 + 后台管理（回收站 / 财务 / 日志），不能管账号；员工：仅查看。路由 meta.roles 与后端 require_role 双层控制。

4.2 商品档案

SPU / SKU 两级结构，分类 / 单位 / 重量单位维护，商品图片上传，条码 / 规格 / 成本 / 售价 / 库存字段完整。

4.3 扫码出入库

扫码 / 条码 / 编码快速出入库，实时扣加库存，流水全程留痕，低库存提示。

4.4 采购入库

供应商管理 + 采购单（草稿 / 确认）+ 扫码建单 + 批量入库，明细写入库存流水与成本基础。

4.5 销售出库

销售单草稿 CRUD + 折扣，确认出库自动减库存，可回滚。

4.6 财务对账

成本快照（出库固化成本）、毛利分析（总额 / 成本 / 毛利 / 毛利率 / 单数 / 件数）、按渠道分组对账、日期过滤、员工可见性控制。

4.7 库存分析

汇总、分类库存、库存排行、销售排行、慢动销、低库存、30 天趋势，员工可查看。

4.8 标签打印

60×40 默认画布、元素整体缩放、三段式自动排版、常用发件人、布局模板（LabelTemplate）、一维 / 二维码元素；打印用 display:none 隔离后台布局，避免多页空白纸。

4.9 渠道追踪

销售渠道管理（天猫 / 抖音 / 未指定等），按渠道统计销售与毛利。

4.10 审计日志与清理（v1.1.1）

关键操作全程留痕；DELETE /api/audits 手动清理（boss / admin，按日期或清空）；启动自动清理默认保留 90 天（AUDIT_RETENTION_DAYS），清理动作本身留痕。

4.11 设置中心（v1.1）

UI 外观自定义（亮 / 暗 / 随机 + 预设主题 + 背景图 DIY）；数据存储安全迁移（备份 / 校验 / 回滚，仅 boss / admin）；云端备份占位入口。

4.12 终端背景主题系统（v1.2 起）

品牌登录页加载动画（约 2.5s，prefers-reduced-motion 跳过）；主界面全直角工业风设计令牌（黄 #fff500 / 青 #14d0d0、斜线网格、HUD 角标）；主题绑定背景（谷地黄 → bg_day_05 白天、武陵青 → bg_night_01 夜晚），上传自定义背景优先级最高。

6.2 本地运行（Windows）

一键启动（推荐）：双击根目录 start.bat —— 自动拉起后端（8000）与前端（5173）、首次自动装依赖、就绪自动打开 http://localhost:5173；停止用 stop.bat。

# 手动启动
cd backend
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

cd frontend
npm install
npm run dev        # 打开 http://localhost:5173
主题 / 背景偏好走后端 UserPreference（GET/PUT /api/settings/preference），须同时开启后端；仅开前端 dev（5173）不启后端（8000）会导致主题设置无法持久化。v1.3.3 起即使后端暂不可用，本地缓存也会兜底显示，随后自动校准。

6.3 其他电脑 / 局域网访问

拷贝项目（或 git 拉取）→ 安装 Python 3.10+ 与 Node 18+ → 双击 start.bat → 本机访问 localhost:5173，局域网其他设备访问 http://本机IP:5173（前端 dev 已代理 /api、/static 到后端）。

6.4 Docker 部署

cd deploy
copy .env.example .env      # Linux: cp .env.example .env
docker compose up -d --build
  • 前端 http://localhost；健康检查 http://localhost/api/health 返回 {"status":"ok"}。
  • 停止 docker compose down（保留 pgdata 数据卷）；彻底移除 docker compose down -v。
  • restart: unless-stopped 自动自愈 backend 早于 db 就绪时的连接重试。
  • 生产必改：deploy/.env 中 POSTGRES_PASSWORD / SECRET_KEY / BOSS_PASSWORD。
  • Docker Hub 拉取超时：daemon registry-mirrors 加入国内加速镜像后重启 Docker Desktop。

6.5 数据库迁移（SQLite → PostgreSQL）

在 backend/.env 设置 DATABASE_URL=postgresql+psycopg2://inventory:<password>@127.0.0.1:5432/inventory（Docker 部署改 deploy/.env）；启动后端，ensure_schema() 自动按库类型建表 / 迁移。

6.6 数据存储位置迁移（设置中心）

仅本机 SQLite：设置中心 → 数据存储 → 选择新目录，系统自动执行备份 → 拷贝 → 校验 → 回滚兜底；拒绝迁移到当前目录子目录 / 相同目录。

九、回收站 / 智能筛选 / 权限说明

9.1 回收站（v1.3）

  • 批量删除（商品档案勾选 → 批量删除，仅 boss / admin）：货品标记 deleted_at 软删除，进回收站，历史出入库 / 采购 / 销售流水全部保留，可还原。
  • 回收站列表：显示删除时间 / 剩余清理天数倒计时。
  • 批量还原：一键恢复为正常商品。
  • 彻底删除：物理删除货品 + 清关联数据（库存流水 / 采购明细 / 销售明细 / 图片 / 规格），不可恢复，二次确认。
  • 自动清理：服务启动时物理清除超过 30 天仍在回收站的数据。

9.2 智能筛选

「商品档案 → 批量删除」弹窗的智能分析：按时间线（如 30 / 90 / 180 天）调用 GET /api/recycle/analyze，返回建议关注清单 —— 库存为空 或 最后变动距今超过所选天数 的货品，含积压天数与原因，可勾选直接批量移入回收站。
